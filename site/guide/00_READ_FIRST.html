你的任务

读完本文件和 docs/ 导读后，阅读者应直接掌握：

  1. 贾宝龙公理体系研究的是存在与非存在，而不是某一个特定宇宙。
  2. 贾宝龙绝对真理以 undefined 的零正面边界为根部，记为命题 (U)。
  3. 实际存在是不完美的动态，绝对完美只能是静态形式。
  4. 第一拍的最小实际结构是 PR，PR、ER、LE 与具体 RULE 组成生成系统。
  5. 七条不同论证共同说明第一拍为什么必须具有 PR 核心。
  6. 从 PR、混沌、类物质、类化学、遗传、选择到第一细胞存在连续研究链。
  7. 研究者和意识在涌现链内部出现，并能反向认识自己的来源。

核心定义

Undefined 与绝对真理

undefined 不是对象、物质、空间、时间或原因，而是终极根部没有任何正面本体规定的边界角色。绝对真理命题为：

\[ U:\quad \forall M\in\mathfrak D\, \forall P\in\mathrm{Pos},\, \neg P(b_M). \]

实际存在与动态

实际存在就是实际发生。绝对完美、完全静态、自足的形式只属于静态描述域；真实存在必须带有持续差异和动态。

PR–ER–LE–RULE

  • PR：实际关系中的非固定回入与第一拍核心。
  • ER：暂时形成的实体—关系局面、结构记忆和局部邻接。
  • LE：局部、延迟、有限和按需实施的求值与截断。
  • RULE：决定 ER 如何更新、LE 如何处理以及是否形成混沌和更高层结构的具体规则。

关系链为：

\[ \text{First Actuality} \longrightarrow PR \longrightarrow PR\text{--}ER\text{--}LE \xRightarrow{\text{RULE}} \text{Chaos} \longrightarrow\text{ProtoMatter} \longrightarrow\text{ProtoChemistry} \longrightarrow\text{Heredity} \longrightarrow\text{Selection} \longrightarrow\text{Protocell}. \]
