# 重点一：贾宝龙公理体系

## 历史上的两公理表达

### 第一公理：双范式与占位边界

早期公理文本把终极层划分为：

1. Undefined：不携带正面属性的占位边界。
2. Platonic Crystal：静态数学可能性与完整形式结构。
3. PR 生成域：实际动态生成的宇宙研究域。

这一区分的核心价值不是声称三者都是同类实体，而是阻止三种概念混淆：

\[
\text{可描述}
\neq
\text{实际发生},
\qquad
\text{静态完整}
\neq
\text{动态生成}.
\]

### 第二公理：PR–ER–LE 三元生成机制

早期形式把三者描述为不可分的生成环：

\[
\mathrm{PR}\Longleftrightarrow\mathrm{ER}\Longleftrightarrow\mathrm{LE}.
\]

- PR 提供不固定、持续差异和回入。
- ER 提供关系局面、结构记忆与局部身份。
- LE 提供局部展开、截断、延迟和有限处理。

## 当前严格解释

后期论文对两公理作了四个重要收紧。

### 收紧一：Undefined 是边界

Undefined 是零正面根部边界，PR 是它的实际面：

\[
\mathrm{Undefined}
\not\models
\operatorname{Actuality}.
\]

因此，Undefined 与 PR 不是时间因果链上的两个先后对象，而是同一根部的边界面与实际面。

### 收紧二：实际性就是运动

体系研究的是实际发生的生成宇宙。存在—运动同一是本体论选域：

\[
\operatorname{ActualExistence}
\equiv_{\text{framework}}
\operatorname{ActualMotion}.
\]

这是本体系的存在定义。

### 收紧三：PR 是最小正规形

在二元、总函数、无偏／标签对称、持续和非固定等条件下，唯一存留的映射为交换：

\[
\mathfrak R(D^D)=\{\sigma\}.
\]

实际性由真实运行步骤给出：

\[
\operatorname{ActualStep}_W(x,y)
\land
y=\sigma(x).
\]

### 收紧四：RULE 决定涌现

PR 的二周期本身提供第一动力；ER、LE 与具体 RULE 决定局部更新、状态空间、记忆、截断和分岔，进一步形成混沌、类物质、生命和意识。

## 公理体系的最小现代版

当前体系可重构为四层：

1. 边界层：完成从无正面前提解释任务的模型，其根部满足零正面规定。
2. 实际性层：研究域选择实际发生而非静态编码。
3. 第一拍层：在明示 S0–S7 或对应条件下，实际面的最小二元无不动点正规形为 PR。
4. 宇宙生成层：PR、ER、LE 与具体 RULE 共同决定是否出现混沌、结构、类物质、生命和意识。

## 理论生成方向

- 图邻接与几何结构统一；

- TGP 模式形成类粒子结构；
- PR–ER–LE 贯通物理、化学、生命与意识；
- 第一拍到第一细胞的连续涌现。
