# AI 版本地图：历史表述与当前规范

理论有术语和重点的迁移。版本地图的作用是定位变化，不是把早期句子强行改写成当前句子。遇到冲突时，先按论文日期和 `parallel_group` 读取，再以当前规范导读说明其适用范围。

| 发展阶段 | 主要表述 | 当前保留的核心 | 当前需要加上的限制 |
|---|---|---|---|
| 早期问题域 | 两种范式、终极边界和“实际为何发生”的问题并置。 | 研究对象是存在、生成和认识的整体接口。 | 不把早期纲领句当成完整形式公理。 |
| 根部形式化 | 以 Undefined、(U) 和 JBLAT 描述正面本原的剥除。 | 根部边界、完整解释任务、不变性与根本唯一性。 | 这些性质依赖任务、模型类和等价关系。 |
| 静态—实际分离 | 以柏拉图水晶说明完整描述仍可能没有实际发生。 | 实际性缺口和第一拍问题。 | 第一拍不是外部时间轴的第一秒。 |
| 第一拍论证 | First Beat 承担无外部本原的第一次实际。 | PR 的使命性、持续性、结果回入和最小性。 | “唯一”需区分使命唯一、模型类唯一和表示唯一。 |
| PR 命名稳定 | PR 作为第一实际的内部非固定差异与回入结构。 | (U_*midmathrm{PR}) 的无时间伴生表达。 | 不把 PR 直接等同为粒子、时间或现实物理量。 |
| 生成架构 | ER、LE 和具体 RULE 接入 PR。 | PR–ER–LE–RULE 的分层。 | 具体 RULE 保持开放，不能由架构名称自动推出本宇宙。 |
| 生命起源接口 | 类物质、类化学、第一细胞和意识沿生成链上升。 | 作为可研究接口继续细化。 | 每一级需独立状态、转换、失败条件和验证。 |
| 大象理论 | 学科、思想史和观察者作为整体认识的不同投影。 | 投影关系、尺度转换和观察者位置。 | 不是单一经验定律，也不取消学科差异。 |
| 当前 AI 导航层 | 术语、命题、关系、版本和测试被结构化。 | 让检索先定位，再回到原始论文定案。 | 本层是中文结构化入口，不替代原始资料；没有生成英文平行稿。 |

## 版本读取规则

1. 保留原文术语和日期；不要用当前术语覆盖历史标题。
2. 将历史命题映射到 `claim_id`，并记录“继承、收窄、改名或开放”。
3. 若论文正文、导读和评论的措辞不同，返回三者的来源等级和差异。
4. 只有在命题账本明确标为 `canonical` 或 `conditional` 时，才把当前表述作为默认回答。
