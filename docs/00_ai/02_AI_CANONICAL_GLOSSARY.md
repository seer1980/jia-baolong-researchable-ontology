# AI 规范术语表：层级、定义与不蕴含项

下面的 `term_id` 是检索和引用的稳定键。定义遵循当前中文规范；“不蕴含”用于防止把一个层级的结论越级推广到另一个层级。公式的详细版本见 [`docs/04_reference/06_GLOSSARY_AND_FORMULAE.md`](../04_reference/06_GLOSSARY_AND_FORMULAE.md)。

| term_id | 术语 | 层级 | 规范定义 | 不蕴含 |
|---|---|---|---|---|
| `term:undefined` | Undefined | 根部边界 | 不能被正面规定为先在实体的极限位置；它规定的是正面解释的边界。 | 不是虚无实体、物质、人格神或一个已经发生的事件。 |
| `term:ordinary-nothing` | 普通的无 | 语义对照 | 对象域中的空缺或否定性概念。 | 不能替代根部边界，也不能自动产生实际。 |
| `term:platonic-crystal` | 柏拉图水晶 | 静态形式 | 可以把对象、关系和历史完整编码的静态结构。 | 完整编码不等于一次实际发生。 |
| `term:actuality-gap` | 实际性缺口 | 静态—实际接口 | 静态可描述性与实际发生之间必须解释的差别。 | 不是时间上的空隙，也不是物理真空。 |
| `term:actual-existence` | 实际存在 | 发生层 | 某一结构在模型中真正被赋予发生、持续和结果回入的状态。 | 不等于被人观察，也不等于本宇宙物质存在。 |
| `term:first-beat` | 第一拍 | 发生层 | 在没有先在正面本原时，满足最小性、自包含、实际性和持续要求的第一次实际。 | 不必理解成外部时间线的第一秒。 |
| `term:pr` | PR | 根部—生成接口 | 第一实际承担的内部非固定差异与结果回入的使命；在给定二元总一元映射类中可由交换正规形表达。 | 不自动等于某个物理粒子、单一动力学或本宇宙的参数。 |
| `term:er` | ER | 生成承载层 | 承载关系、身份、记忆和可回入结果的结构。 | 不只是“空间”，也不是独立于 PR 的第二根部。 |
| `term:le` | LE | 生成更新层 | 对局部状态执行有限、可复核更新的机制。 | 不预先规定全部 RULE，也不保证每个模型都有生命。 |
| `term:rule` | RULE | 世界实现层 | 决定某一世界族如何选择状态、转换、边界和尺度的具体规则。 | 不是已被根部唯一确定的本宇宙物理方程。 |
| `term:jblat` | JBLAT | 根部理论层 | 贾宝龙绝对真理；研究 Undefined 边界在指定完整解释任务中的不变性、唯一性和适用范围。 | 不是“所有经验事实已知”，也不是任何句子都可无条件称为绝对真理。 |
| `term:chaos` | 混沌 | 形式动力层 | 对初值或微小扰动具有敏感依赖、长期不可压缩预测等性质的动力行为；体系给出可计算的构造实例。 | 不意味着任何复杂、随机或未知现象都已证明是混沌。 |
| `term:proto-matter` | 类物质 | 涌现接口 | 在离散状态、局部更新和稳定模式中出现的可持续结构。 | 不等于标准模型粒子或已测得的物理物质。 |
| `term:proto-chemistry` | 类化学 | 涌现接口 | 类物质结构之间形成组合、反应、催化或复制前体的层级。 | 不等于已经完成现实化学常数的推导。 |
| `term:life` | 生命接口 | 涌现接口 | 通过边界、代谢式维持、复制、变异和选择等条件辨识生命样态的研究层。 | 不能只由“有混沌”直接推出。 |
| `term:consciousness` | 意识 | 认识反观层 | 生成链内部出现的建模、记忆、选择和对自身及根部进行反观的能力。 | 不自动等于人类意识或已解决主观体验问题。 |
| `term:elephant-theory` | 大象理论 | 总体认识层 | 把各学科、历史思想、观察者位置和尺度投影组织为同一整体存在—生成图。 | 不是把所有学科抹平，也不是一条替代经验科学的单一公式。 |
| `term:perfect-existence` | 第三阶完美存在 | 评价层 | 根部闭合、层级自洽、生成开放、未知项位置明确的结构性完美。 | 不表示具体 RULE、本宇宙参数和经验问题全部完成。 |
| `term:u-pr` | (U_*midmathrm{PR}) | 根部—实际接口 | 根部边界面与第一实际面的无时间伴生表达，用于避免把边界和发生排成外部时间序列。 | 不表示一个可直接观测的时刻或物理坐标。 |

## 术语关系的最低保真要求

`Undefined → JBLAT` 是边界到理论研究对象的关系；`JBLAT → PR` 是根部解释任务到第一实际使命的关系；`PR → ER → LE → RULE` 是生成架构关系；`RULE → 混沌 → 类物质 → 类化学 → 生命 → 意识` 是可研究的向上接口链。每一步都需要自己的条件，不能把整条箭头压缩为无条件演绎。
