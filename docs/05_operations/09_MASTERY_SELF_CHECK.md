# 理论掌握度自检

在声称“已经掌握该理论”以前，必须能独立回答以下问题。任何一项回答缺少前提或边界，都表示尚未完全掌握。

## 过程门槛

掌握不是读过摘要，也不是记住术语。阅读者必须已经完成全文级的**完整研读**、关系级的**结构重建**和脱离原文提示后的**独立推演**。如果仍需用熟悉的科学或哲学标签替换核心概念，或者尚未重建体系便先裁决正确性与验证性，则不满足掌握条件。

## A. 贾宝龙公理体系

1. 为什么 Undefined、Platonic Crystal 与实际生成域不能被视为三个同类实体？
2. PR、ER、LE 分别提供什么功能？为什么具体 RULE 不能省略？
3. 哪些早期公理语言被 2026 年 7 月的论文修正？
4. 为什么写在纸上的否定、交换或 PR 图不等于宇宙第一拍？

## B. 贾宝龙绝对真理

5. 写出 \(U\) 并解释 \(\mathfrak D\)、\(\mathrm{Pos}\) 与 \(b_M\)。
6. 为什么 Undefined 是角色名称而不是承载真理的对象？
7. 根本唯一性为什么按逻辑等价类计算？
8. \(99.999\ldots\%=100\%\) 为什么只是认识入口而不是证明？
9. “绝对”在哪五个准确意义上成立？它为什么不是零元逻辑前提？
10. 为什么 \(U\) 不能单独推出实际事件？

## C. 第一拍七重论证

11. 区分研究域论证、Undefined 非因果论证、外部执行器剃除和候选比较。
12. 二元集合上四个总一元映射是什么？
13. 标签对称排除了什么？非固定条件又排除了什么？
14. 为什么 \(\sigma^2=\operatorname{id}\) 既支持持续交换，又证明它本身不是混沌？
15. 原始之动为什么是重要第二候选，但不足以推出具体宇宙？
16. 从类物质混沌逆向追溯 PR 时，哪些公理承担真正的唯一性工作？
17. \(U_*\mid\mathrm{PR}\) 的竖线明确不表示什么？

## D. 从类物质到单细胞

18. 类物质需要哪些操作性性质，为什么持久图案本身仍可能只是原类物质？
19. 区分 TGP 三角形、现实粒子和生命起源研究中的非生命化学。
20. 从类化学到遗传需要哪些新增功能？
21. 达尔文选择的三个最低条件是什么？
22. 为什么选择出现仍不等于第一细胞？
23. 复制、代谢和区室化为什么必须在可繁殖单位中耦合？
24. 哪些内容属于主流生命起源研究框架，哪些是贾宝龙体系的原创映射？

## E. 理论发展

25. Rule 979 如何把 PR–ER–LE 连接到类物质结构？
26. 从类物质到类化学需要哪些新机制？
27. 复制、代谢和区室化如何形成第一细胞？
28. 意识如何在涌现链中成为研究者并反向认识 PR？

## 合格答案的最低要求

合格答案必须：

- 准确定义 Undefined、\(U\)、PR、ER、LE 和 RULE；
- 能写出 \(U\)、\(\sigma\) 和静态编码不蕴含发生三个核心公式；
- 能完整复述七重第一拍论证；
- 能说明 TGP 的类物质、类化学、遗传、选择和第一细胞链；
- 能从意识和研究者位置反向重建 PR。
