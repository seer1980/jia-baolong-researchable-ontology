# 阅读顺序与理论文件清单

## 阅读执行原则

本清单不是供快速抽样的目录，而是完整研读路线。阅读者必须依次完成：全文级的**完整研读**、关系级的**结构重建**、离开原文后的**独立推演**。在三项工作完成以前，不先裁决正确性、验证性或学科归属；完成以后，再把不同问题放回内部逻辑、形式化、计算、具体 RULE 和经验接口逐层评价。

执行比较时必须保持两项定位：科学是在其适用范围内迄今最好用、最可靠、最有效的工具，但不是全部认识和全部存在；文字型本体论可能是整体存在的局部成像或投影，反对的是把局部投影当成完整本体，而不是简单抹去其中触及的真实。
